# Initial Air — phone app

The Initial Air HVAC site is synced here as a phone-installable web app (no Higgsfield).

**Open on your phone now:**
[Preview the app](https://htmlpreview.github.io/?https://github.com/ryvntrvn-code/ac/blob/cursor/sync-app-to-phone-6d8a/docs/index.html)

**Home Screen install URL** (after GitHub Pages is enabled):
[https://ryvntrvn-code.github.io/ac/](https://ryvntrvn-code.github.io/ac/)

## Add it to the Home Screen

**iPhone**
1. Open the link in Safari.
2. Tap Share.
3. Tap **Add to Home Screen**.

**Android**
1. Open the link in Chrome.
2. Tap **Add to phone** when the banner appears, or use the browser menu **Install app**.

Quotes are saved on the phone. You can also text them to 0414 881 324.
